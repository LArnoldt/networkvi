Changelog
==========

For each release of NetworkVI there will be a documentation of major changes.
The format is based on `Keep a Changelog <https://keepachangelog.com/en/1.0.0/>`_, and this project adheres to `Semantic Versioning <https://semver.org/spec/v2.0.0.html>`_.

[Release 0.2.0]

- Resources and preprocessing scripts for alternative prior knowledge
- Making more NetworkVI arguments public
- Update to sample data in notebooks
- Update to attention interpretability
- Addition of 95% CI calculation in gene and GO interpretability

First release.
